## A small project to practice building, testing, and deploying a simple application. Not a production-style project, but a place to experiment with real workflows, from code and testing to deployment.

# demo-2 objectives
- Run the app locally from start to finish
- Write simple tests and verify results
- Debug and find the root cause of errors
- Build a Docker image and run a container
- Deploy the app to local Kubernetes
- Get familiar with GitHub Actions and understand the basic CI/CD flow

## What is used in the project
- Python / Flask for the main application
- pytest for writing and running tests
- Docker for building and running containers
- Kubernetes, Kind, and Helm for local deployment experiments
- GitHub Actions for CI/CD
- Cloudflare Workers for a small API demo (Demo result: https://steep-fog-d998.demo2-test.workers.dev/)
